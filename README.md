# Fayiz Wedding Invitation – "The Sacred Garden"

Static website for Netlify (drag & drop this folder at https://app.netlify.com/drop).

## Structure
```
index.html        <- the invitation page
netlify.toml      <- Netlify settings
assets/           <- css, js, images, video
```

## RSVP form
On Submit it shows "Submitted", closes the popup and returns to the main page.
Nothing is saved or sent anywhere.
